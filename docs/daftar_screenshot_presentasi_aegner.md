### 💡 Fitur Otomatis Tambahan:
1. **Auto-Fit & Bounded Container**: Seluruh wadah gambar sudah di-fit-kan otomatis. Gambar panjang/lebar **tidak akan terpotong atau keluar layar**.
2. **Smart Extension Fallback**: Jika kamu menggunakan `.png` (misal `slide4.png`) atau `.jpg` (misal `slide4.jpg`), sistem web akan **otomatis mendeteksi dan menampilkannya** tanpa error! 🚀
